# Registro — Aula 05: JSX de Verdade

Uma expressão produz um valor, como `{projeto}`, enquanto um comando executa uma instrução, como `if`. No projeto Nexus, usei expressões para mostrar o nome da loja e o operador ternário para exibir mensagens diferentes na lista de produtos. O erro mais difícil foi deixar dois elementos soltos no `return`, porque aprendi que eles precisam estar agrupados em uma `div` ou em um Fragment. Também aprendi que o `className` é usado no JSX para aplicar estilos CSS e que o Fragment agrupa elementos sem criar uma etiqueta extra no HTML.
