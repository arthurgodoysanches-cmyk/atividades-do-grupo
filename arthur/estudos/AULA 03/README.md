# Registro de Estudos - Aula 03

O experimento que mais me incomodou foi o **Experimento 2 (Peder o que foi digitado)**.
É absurdo pensar que para adicionar um único item novo na lista, o JavaScript precisa apagar e reconstruir todos os outros 500 itens do HTML, destruindo tudo o que o usuário já tinha digitado nos campos e não tinha salvado. 
Isso mostra como o modelo imperativo prejudica a experiência do usuário e dá muito trabalho para gerenciar manualmente.
