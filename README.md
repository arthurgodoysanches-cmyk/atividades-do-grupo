# atividades-do-grupo

Componentes do projeto NEXUS
Cabecalho: exibe o nome da loja e a frase de apresentação.
Cartao: apresenta os produtos, suas descrições e seus preços, recebidos por props.
Lista: mostra as tarefas e informa se estão feitas ou pendentes usando um operador ternário.
App: organiza o cabeçalho, os cartões de produtos e a lista de tarefas.
Conceitos de JSX - Aula 05
Uso de variáveis dentro do JSX com chaves {}.
Uso de className para aplicar estilos CSS.
Uso de map() para renderizar listas e key para identificar cada item.
Uso do operador ternário para mostrar o status das tarefas.
Uso de Fragment (<>...</>) para agrupar elementos sem criar uma etiqueta extra no HTML.
